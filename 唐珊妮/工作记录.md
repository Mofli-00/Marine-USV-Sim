5月7日 项目依赖问题排查与修复记录
本次开发过程中遭遇了一系列由依赖包引发的连锁问题，记录排查过程供后续参考。
1. gameplay-ingredients 包无法下载
项目原依赖 net.peeweek.gameplay-ingredients 通过 GitHub git 链接安装，因网络限制连接超时，导致项目启动时弹出 Package Manager Error。先后尝试了 ghproxy.com、mirror.ghproxy.com 等镜像地址，均因域名解析失败而无效。最终尝试将包源码手动下载放入 Packages 目录，但因下载的是 master 分支而非项目所需的 2019.3.0 版本，引发了 NaughtyAttributes 等二级依赖缺失，导致 400+ 编译错误。
2. AppSettings.cs 编译失败
由于 gameplay-ingredients 包缺失，AppSettings.cs 中对 GameplayIngredients 命名空间、Manager 基类、ManagerDefaultPrefab Attribute 的引用全部报错，导致项目无法编译进入 Play 模式。通过修改 AppSettings.cs，移除相关 using 和 Attribute，将类继承从 Manager 改为 MonoBehaviour，解决了编译错误。
3. Library 缓存损坏
多次修改 manifest.json 与强制重导入操作导致 Unity 资源数据库损坏，场景中出现大面积粉红色材质（天空盒、山体地形）。通过关闭 Unity 后删除 Library 文件夹，重新打开项目强制重建缓存，并重新执行 Addressables Build，场景一直未恢复正常。
4. 游戏流程卡住
修复编译错误后发现 Play 模式下游戏会卡在加载帧无法进入赛艇界面。排查发现原因是 gameplay-ingredients 的 Manager 系统负责自动创建 AppManager 对象并初始化游戏流程，包缺失后该流程中断。通过 git 恢复原始的 AppSettings.cs 与 manifest.json，并重建 Library，但始终无法解决。
总结：最后项目已经完全无法打开，会有闪退问题。




## 4月30日 天气系统开发
继成功复刻项目后，本次工作重点转向天气视觉系统的开发，为赛艇场景添加动态天气效果。
1. WeatherManager 核心脚本
天气状态管理： 在 Assets/Scripts/Environment/ 下创建 WeatherManager.cs，实现了五种天气状态的统一管理：晴天、阴天、雨天、暴风雨、大雾。每种天气均配有独立的光照强度、雾效密度、环境光颜色等参数，可在 Inspector 中直接调节。
平滑过渡系统： 基于 SmoothStep 插值协程实现天气之间的平滑切换，默认过渡时长 3 秒，光照、雾色、环境光全程插值过渡，避免天气突变的割裂感。
2. 粒子雨效果
创建 RainParticles 与 HeavyRainParticles 两套粒子系统，分别对应普通降雨与暴风雨场景。使用 Stretched Billboard 渲染模式模拟雨丝拉伸效果，发射速率由 WeatherManager 在运行时动态控制，普通雨 300粒/秒，暴风雨 800粒/秒。
3. 闪电系统
基于 Point Light 实现随机闪电效果，通过协程控制闪烁节奏（间隔 3~8 秒随机触发），模拟双闪效果增强真实感，仅在 Stormy 天气状态下激活。
4. 场景集成
在 demo_island 场景中创建 WeatherSystem 空对象，挂载 WeatherManager 脚本，关联场景中的 Directional Light、RainParticles、HeavyRainParticles、LightningLight，实现了运行时在 Inspector 中切换天气类型的功能。



##4月9日 仿真环境进阶与礁石细节开发记录

继上次地形基础搭建完成后，本次工作重点转向了自定义模型融合、物理材质解绑以及海浪环境特效（VFX）的开发。

  1. 外部模型集成与材质解绑 (核心技术突破)
OBJ模型导入与纹理重构： 针对导入的 Reef（礁石）模型材质被“锁死”（只读状态）的问题，通过创建独立的 HDRP/Lit 材质球并手动映射纹理贴图，成功实现了外部模型与场景视觉风格的统一。

UV与平铺（Tiling）优化： 针对大型礁石模型，通过精确调整材质球的 Tiling 比例，解决了纹理拉伸问题，使礁石的岩石纹理颗粒度与原生 Terrain 地形保持一致。
![新添加的岛屿模型](new_Island_terrain.png)

  2. 海浪动力学视觉开发 (VFX Graph 应用)
礁石浪花特效实现： 利用 Visual Effect Graph 开发了专用的 VFX_Reef_Foam 系统。通过 Turbulence（湍流） 节点模拟了真实水沫的随机晃动感，并利用 Size over Life 曲线实现了浪花飞溅扩散的动态效果。

HDRP 高动态渲染调优： 针对海面高亮反射导致的视觉淹没问题，通过调整粒子的 HDR Intensity（曝光强度）和 Alpha 渐变，确保浪花在不同光照角度下均清晰可见。

高度对齐与坐标修正： 精确校准了 VFX 发射器与 Water Surface 的 Y 轴相对位置。但实际效果好像并不理想，场景显示不出浪花效果。
